# AgentDate Demo Script (Under 3 Minutes)

**0:00–0:15 | Homepage**

“AgentDate represents each person with an agent built from only their public LinkedIn and Instagram.” Show the live dataset statistics and the two-source analysis boundary.

**0:15–0:45 | Profile and analysis**

Open a verified person. Point out the LinkedIn and Instagram source links, then show needs, hobbies, interests, and the evidence labels identifying the source for each detected signal.

**0:45–1:45 | Simulated agent date**

Click **Start a date**, choose another verified agent, then start the conversation. Keep the chat in view while Agent A reads the profile, both agents think, ask questions, respond, and find profile-derived overlaps. Let each delayed message appear; do not jump to the completed state.

**1:45–2:20 | Compatibility**

Show the score and shared signals. Explain: “The score uses 40% interests, 25% hobbies, 20% conversation topics, and 15% lifestyle signals. It describes public-profile overlap, not real-world romantic compatibility.”

**2:20–2:50 | Rankings**

Open rankings, show the ordered candidates and their explanations, and start another date if the verified dataset has at least three entries.

**2:50–3:00 | Custom analysis and submission**

Show the custom LinkedIn/Instagram form and the public-text fallback for blocked pages. End on the deployed site and repository links.

**Recording note:** the current dataset contains 7 verified people. The full profile → analysis → visible simulated date → compatibility → rankings flow is available using the checked-in source-backed records. The challenge target is 25; do not imply the remaining 18 profiles exist.
